# ZeroWatt — Intelligent Energy Conservation Platform

> **Smart Classroom Bharat ✦ F1.0 Engineering Blueprint**  
> *"An engineering classroom that thinks before it consumes."*

A student-built exploration of spatial sensing, environmental intelligence, measurable power control, and human-first automation — built with **React**, **Vite**, and **Tailwind CSS**.

---

## ⚡ Numbered System Sections & Engineering Architecture

1. **01 / Core System Features (Interactive 7-Capability Grid)**:
   - **Feature 1 — Efficient Energy Saving**: Load gating & daylight harvesting.
   - **Feature 2 — AI-Driven Actions**: 5-tier priority matrix decision engine.
   - **Feature 3 — Smart Energy Monitoring**: Calibrated INA219 shunt telemetry.
   - **Feature 4 — Reduced Emissions**: Indirect carbon footprint abatement.
   - **Feature 5 — Real-Time Person Detection**: Edge camera CV spatial perception.
   - **Feature 6 — Occupancy Estimation**: Cluster density & ventilation scaling.
   - **Feature 7 — Smart Alerts & Notifications**: High-speed threshold alert dispatch.
   - *Default state*: Minimal 7-icon gallery only. Click reveals animated horizontal bar graph on left, description/benefits on right. Click again collapses.

2. **02 / Live System & Command Simulator**:
   - 3D spatial multi-zone live state (Front Podium, Middle Benches, Window Perimeter).
   - SCD30 environmental node (CO₂, Temp, RH).
   - INA219 power allocator with controllable load dial slider.

3. **03 / Interactive System Lab (Viva Flow Rehearsal)**:
   - 7-step guided demo runner for evaluators and faculty.
   - Live presenter script narration banner.
   - Dynamic priority reallocation breakdown matrix (P1–P5).

4. **04 / Evidence Engine**:
   - Real-time animated SVG power curve trace (Requested vs. Allocated vs. Measured W).
   - Chronological event log table with 1-click CSV export.

5. **05 / Hardware Architecture & Validation**:
   - DevKitC ESP32-S3 pin mapping and bus topology.
   - Academic principles from NIT Tiruchirappalli.
   - Galvanic safety boundary and cooperative state machine authority.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)
- npm

### Installation
```bash
# Install dependencies
npm install
```

### Running Locally (Development)
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### Building for Production
```bash
npm run build
```
Generates optimized static assets in the `dist/` directory.

### Previewing Production Build
```bash
npm run preview
```
